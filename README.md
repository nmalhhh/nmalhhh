### 📌 Giới thiệu bản thân
- 🎓 **Học vấn:** Sinh viên chuyên ngành Kỹ thuật Phần mềm / Hệ thống Thông tin tại **Đại học FPT**.
- 🎯 **Định hướng:** **Software Business Analyst (BA) / IT Com-Tor**, kết hợp giữa tư duy phân tích yêu cầu nghiệp vụ và nền tảng kỹ thuật lập trình Web.
- 💡 **Thế mạnh chuyên môn:**
  - **Khảo sát & Đặc tả yêu cầu:** Thành thạo quy trình viết tài liệu SRS, phân tích Use Case, User Stories, Quy tắc nghiệp vụ (Business Rules) và Tiêu chí nghiệm thu (Acceptance Criteria).
  - **Thiết kế giao diện & Luồng hệ thống:** Xây dựng luồng người dùng (User Flow), Wireframe và Prototype tối ưu trải nghiệm UI/UX.
  - **Kỹ thuật & Dữ liệu:** Hiểu kiến trúc Web (Java Web, MVC), cấu trúc cơ sở dữ liệu quan hệ, viết câu lệnh truy vấn SQL và kiểm thử tính năng (Software Testing/QC).
- 🌐 **Ngoại ngữ:** Tiếng Nhật **JLPT N4** (đang tiếp tục trau dồi lên N3 để làm việc với khách hàng và dự án Nhật Bản).
